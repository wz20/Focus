## 本次功能
- 截止时间 deadline 为独立、可空的 ISO 时间；可以只有截止时间而没有计划起止时间。
- 拖动时间轴计划横条只改计划起止，不改截止时间。时间轴用小菱形标记独立截止时间。
- 计划结束晚于截止时间、或截止时间已过去时提示，但不强制改期或禁止记录。
- 新任务表单建议开始前10分钟、截止前30分钟提醒；关联时间未填时不提醒。可选不提醒、到点、提前5/10/15/30分钟、1小时或1天。
- 旧版任务读取时保留 ID、内容、时间、状态、归档；新增截止字段为空，旧任务的提醒默认关闭。
- 前台使用不抢焦点的应用内提醒弹窗；后台通过 Electron Notification 请求系统通知。多条一起到点合并成一次系统通知，页内列表可逐条查看/确认。
- 点击提醒打开对应任务；编辑任务有未保存草稿时先保留草稿，关闭表单后再打开提醒任务。
- 完成、归档、删除、关闭提醒和改期时撤销旧提醒。进入 ing 后不再发“开始”提醒，但未完成的 deadline 提醒仍可触发。
- 提醒发送去重和未确认记录写入独立 reminders.json；重启不会重复发送同一提醒，未确认提醒可继续查看。不会将任务数据上传云端。
- 测试入口：应用顶部“数据与帮助 → 测试提醒”；Mac 菜单“帮助 → 测试任务提醒”。

## 必须知道的提醒边界
- 本版由 Electron 主进程每5秒检查，并在电脑 resume 后补查，非毫秒级闹钟。
- 仅 Focus 进程运行时有效。macOS 单独关闭窗口、但不退出 Focus，可继续后台检查。
- Cmd+Q 完全退出、关机或休眠时不能准时提醒。启动/唤醒后，开始时间过去不超过15分钟、deadline过去不超过24小时的未提醒事件会合并补提醒；更早的事件不会集中刷屏。
- 系统通知是否显示还取决于 macOS 权限、专注模式及运行环境。Notification “show”事件只作为 Electron 展示确认，不代表用户已阅读。
- 未收到系统通知时，待确认提醒仍保存在应用中。可通过“测试提醒”检查。
- HTML 预览仅支持页面打开期间的页内提醒，与 Electron 应用各自保存数据；不等同于系统后台提醒。

## 更新建议
先在旧版导出JSON备份，退出旧版，再用新的Focus.app替换“应用程序”中的旧版。不要删除用户数据目录。
更新后从“数据与帮助 → 测试提醒”验证。建议先使用一条短期测试任务，再用于重要工作。
首次提示身份不明时，仅在确认来源后按macOS“隐私与安全性”批准本应用；不要关闭系统安全保护。若提示“已损坏”或“将损坏电脑”，不要忽略，请保留提示用于排查。
